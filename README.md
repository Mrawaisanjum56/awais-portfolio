# Awais Anjum — Portfolio

A premium, responsive static portfolio for Awais Anjum, a software engineering graduate focused on Python, backend development and practical AI applications.

## Run locally

No build step or package installation is required:

```bash
cd awais-portfolio
python3 -m http.server 8080
```

Open `http://localhost:8080`.

## Deploy to Netlify

This is a static site. Point Netlify at the repository and use:

- **Build command:** none
- **Publish directory:** `.`

The site can also be deployed by dragging the repository folder into Netlify Drop.

## Personal details to update
