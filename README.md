## About the Project

This repository contains the source code for my personal portfolio website.

Designed as more than a conventional developer portfolio, the website combines an editorial visual style, interactive navigation, thoughtful animations and a clean presentation of my technical interests and projects.

It represents who I am as an emerging software engineer, what I am learning, and the problems I aim to solve through technology.

**My focus areas:**
- Python and Backend Engineering
- Django and Web Application Development
- Artificial Intelligence and Machine Learning
- Database Design and Management
- Practical, problem-oriented software development

## Design Philosophy

The portfolio follows a hybrid editorial and interactive design direction.

Rather than relying on generic templates and conventional project cards, the experience uses:

- A warm, minimal colour palette.
- Strong editorial typography.
- Asymmetrical layouts and intentional whitespace.
- Five interactive navigation panels.
- Contrasting light and dark sections.
- Subtle animations and transitions.
- Responsive layouts for desktop, tablet and mobile.

## Featured Project

### AgriMarket AI — AI-Based Agricultural Marketplace

My final-year project explores how software engineering and machine learning can address a practical agricultural problem.

**Core concept:** An online agricultural marketplace with automated wheat quality assessment.

**Technologies involved:**

- Python
- Django
- MySQL
- TensorFlow
- MobileNetV2
- HTML, CSS and JavaScript

The system combines agricultural marketplace functionality with an image-classification model designed to assess wheat quality.

## Run Locally

You can run the website locally without installing a frontend framework or backend server.

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Open the project directory**

```bash
cd awais-anjum-portfolio
```

**3. Launch the website**

Open `index.html` directly in your browser, or use the Live Server extension in Visual Studio Code.

**4. Customize the portfolio**

Before deployment, update:

- Professional portrait.
- Email address.
- GitHub and LinkedIn URLs.
- Resume file.
- Project screenshots.
- Project repository and demonstration links.
- Website domain and SEO metadata.

## Performance and Accessibility

The website is designed with the following principles in mind:

- Responsive layouts across common screen sizes.
- Semantic HTML elements.
- Keyboard-accessible navigation.
- Descriptive image alternative text.
- Optimized image assets.
- Reduced-motion support.
- Lightweight frontend implementation.
- Search-engine-friendly page structure.

Performance and accessibility scores should be verified against the deployed version rather than assumed.

## Deployment

The website can be deployed as a static site using Netlify.

General deployment workflow:

1. Push the project to GitHub.
2. Connect the repository to Netlify.
3. Configure the deployment settings.
4. Deploy the website.
5. Connect a custom domain if available.
6. Configure HTTPS.
7. Submit the sitemap through Google Search Console.
